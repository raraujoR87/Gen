# Dependencies for running the local paper-trading service (RUN_LOCAL.md /
# run_local.bat) with a SQLite database — everything in requirements.txt
# EXCEPT asyncpg and modal, which this mode never imports:
#
#   - asyncpg: only used via DATABASE_URL's postgresql+asyncpg:// driver
#     (backend/db/session.py). SQLite uses aiosqlite instead. asyncpg often
#     has no prebuilt wheel yet for the newest Python releases (e.g. 3.14 at
#     time of writing) and fails to build from source without a full C
#     toolchain — skipping it avoids that build entirely for local use.
#   - modal: only used by Modal.com cloud deployment; backend/security/kms.py
#     already imports it behind a try/except ImportError guard, so its
#     absence is a supported, tested configuration (the dev-fallback KMS key
#     path), not a hack.
#
# Keep this file's other pins in sync with requirements.txt by hand — it is
# a subset, not a fork.
